Top stories

1. Anthropic closes its IPO — the largest in history, with $119.5B raised in total

Anthropic closed its initial public offering of 1.127 billion Class A shares at $83.00, including the underwriters' full exercise of their 147M-share option, for about $93.5B in gross proceeds — roughly $91.6B of it to Anthropic. A concurrent private placement sold 313.25M Class N shares to AMD, Broadcom, Google, Micron, Microsoft, NVIDIA, and TSMC for about $26.0B, bringing total gross proceeds to approximately $119.5B. ANT began trading on Nasdaq on November 19, opened at $111.50, and closed at $97.17 — up 17% from the offer price — for a valuation of about $1.5T at the close (near $2T fully diluted at the open). CEO Dario Amodei used the occasion to restate a safety commitment: Anthropic will pace training and deployment "taking as long as is necessary to have confidence that they are safe and will remain under human control," and "will not bend to either business or political pressure."

Why it matters: The raise beats SpaceX's $75B June IPO as the largest ever, and the first-day pop — with roughly a trillion dollars of shares set to free up over the next year as lockups expire — makes ANT the market's live verdict on frontier-lab economics. The more durable signal is the buyer list: the same chipmakers and hyperscalers that supply Anthropic's compute also bought in directly, and Amodei tied the listing to a public pacing commitment rather than a growth sprint.

Sources: Anthropic, Latent Space

2. Google opens Genie 4, its world model, to developers

Google opened Genie 4 to developers through the Gemini API: a real-time world model generating 720p video at 24fps with WASD control and 48kHz audio, delivered over WebRTC/WebSocket on the new Live Interactions API. It is the interactive-world-model counterpart to Google's text and image generation stack, aimed at games, simulation, and embodied-agent training rather than static content.

Why it matters: World models are moving from demos to developer APIs — controllable, real-time, and billed per use. If Genie 4 works as advertised, it gives developers a cheap way to generate interactive environments on demand, and it puts Google in direct competition with the game-engine and simulation incumbents for the next layer of agent training data.

Sources: Latent Space

3. AWS lets agents buy software on your AWS bill

Amazon extended Bedrock AgentCore payments to AWS Marketplace: agents can now discover and buy x402-enabled software, APIs, data, and content, and pay in USD on the developer's AWS bill — no stablecoin wallet or API keys needed. When a seller replies with a 402 Payment Required and a signed quote, AgentCore checks the session budget, returns a payment token, and the charge lands as a Marketplace line item. Spending limits, approved sellers, and audit trails carry over from the AgentCore payments launch in August, and a new Marketplace connector in AgentCore Gateway helps agents discover sellers; Tavily is among the first verified sellers.

Why it matters: Agentic commerce has been mostly talk and stablecoin demos; this is the first version that fits how enterprises already buy software — invoiced, audited, and capped. The real test is whether companies trust agents with a budget at all, and AWS is betting that familiar billing rails are what tips that decision.

Sources: AWS Machine Learning Blog

4. OpenAI ships a security suite: Daybreak Red and Blue, Codex Security Plugin, PR scans

OpenAI published a batch of security-focused material in one day. Daybreak Red is a reference architecture for supervised security investigations, with safety controls, setup, and monitoring; Daybreak Blue is the onboarding path for the same family of tools. Alongside them, OpenAI demoed PR scans — reviewing security scan results inside a pull-request workflow — and the Codex Security Plugin, which brings security checks into Codex's workflow from setup through results review.

Why it matters: This is the other half of OpenAI's defender push from earlier in the month: not just patching vulnerabilities with models, but packaging the tooling so security teams can run supervised investigations and bake checks into the code-review loop. The supervised framing matters — these are tools for humans doing investigations, not autonomous agents let loose on a codebase.

5. Gemini API gets Tool Retrieval for agents with big tool libraries

Google launched Tool Retrieval in preview in the Gemini API (Interactions API). Instead of sending a full tool library's parameter schemas on every request, an agent keeps the library on standby — the model sees each tool's name and description — and the API loads a tool's full schema only when the model asks for it by name, inside the same request. It works with Gemini 3.6 and later models.

Why it matters: As agents accumulate dozens or hundreds of tools, stuffing every schema into every prompt inflates tokens, adds latency, and degrades tool selection. Deferring schemas is a small, practical fix to a scaling problem every serious agent builder hits — and a sign that the API layer is being redesigned around agents, not single-turn chat.

Sources: Google AI Blog
